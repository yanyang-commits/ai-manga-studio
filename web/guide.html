五分钟，建立你的第一个项目

  1. 进入工作台，新建项目，填写片名、故事想法、受众、视觉风格和目标时长。
  2. 点击“生成阶段提示词”，复制到你使用的 AI 对话工具中。
  3. 把生成的剧本与角色设定粘贴回对应阶段，并进行人工修改。
  4. 在分镜阶段添加镜头，填写画面、运镜、对白与时长。检查总时长是否接近目标。
  5. 记录视听制作与交付信息，完成清单，导出 JSON 备份及 Markdown 制作方案。

当前版本能做什么

多项目管理与复制、全部项目备份、六阶段编辑、自动本地保存、提示词组装、分镜编辑、交付检查、模板搜索，以及 JSON / Markdown / CSV 导出。示例项目《末班列车》是演示内容，添加时会新建一个项目，不覆盖你的现有作品。

当前提供 ChatGPT 账号云端保存，暂不提供独立 Google / Apple 登录、真实模型生成、团队协作和在线渲染。创意联想、检查和模板输出由本地规则生成，不是模型推理结果。

数据与隐私

游客工作区保存在当前浏览器的 localStorage 中，不上传草稿。账号云端工作区通过同源接口保存到当前账号对应的私有云对象，并校验版本避免覆盖。云端编辑未确认保存前，请不要关闭页面。本站不嵌入第三方统计脚本或外部字体，托管服务可能保留基础访问日志。

游客与账号草稿使用两个独立工作区，登录不会自动搬运游客草稿；可点击“导入游客草稿到云端”主动复制，原本地草稿保留。游客之间的草稿不会通过本站互相共享；同一设备、同一浏览器中的不同使用者可能看到本地草稿。浏览器存储受设备、域名和浏览器配置影响，无痕模式或清理网站数据可能导致丢失。本地保存不等于备份，请定期导出 JSON。删除项目需要确认，删除前请先导出。

导入支持本工具 schemaVersion 1 的单项目 JSON 和全部项目备份，单个文件不超过 10MB。导入会创建新项目，不覆盖已有项目。最多保存 30 个项目，每个项目最多 100 个镜头；达到浏览器容量上限时会提示，请立即导出。

多标签页同时打开时，检测到其他标签页更新后会暂停本页保存，避免以旧内容覆盖新版本。请先导出本页全部项目备份，再刷新。若本地内容损坏，本工具不会自动覆盖原存储，会提示临时编辑与导出。

创作辅助与 AI 工具

六个阶段均有本地联想卡、缺失信息检查与官方外部工具链接。点击“展开为 AI 追问”会把联想与项目上下文组合成完整指令；你可以自行复制到所选工具。本地工具不会自动发送草稿到第三方。

提示词库提供 48 条指令，包含故事钩子、三视图、逐镜分镜、配音、字幕和成片复盘。Google / Apple 独立登录与直接模型生成目前不可用，界面会明确标记。

先接入服务端文本生成，服务端保管密钥，前端通过同源接口提交任务。随后增加异步图片、配音与视频任务队列。所有生成能力在真实服务完成前，不会以可用功能展示。

当前不收集用户 API 密钥。未来启用模型生成时需由站点所有者安全配置服务端凭据，再完成费用控制与接口验收。

常见问题

如何更换电脑？
游客在原设备导出项目 JSON，再到新设备导入。账号用户登录同一 ChatGPT 账号后，在云端工作区读取自己的项目。

刷新后为什么没有内容？
请确认使用同一域名、同一浏览器，且没有清理数据。若页面提示无法保存，请立即导出项目备份。

分镜时间和总时长不一致怎么办？
编辑每个镜头时长；工作台会显示累计时长和与目标的差值，帮助你调整节奏。

如何处理 AI 素材的商用问题？
逐项确认模型服务、音乐、字体、角色和素材的授权，以及目标发布平台的现行要求。本工具的检查清单不能替代对具体授权条款的核查。
