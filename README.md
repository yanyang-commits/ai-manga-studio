# 漫序 MangaFlow

一个面向独立创作者与小型制作团队的 **AI 漫剧全流程工具站**。把故事企划、剧本、角色、分镜、视听制作和剪辑交付放进一个可保存、可导出的工作台。

> **v0.1 是可使用的本地工作版。** 提示词由规则组装，未调用模型；图片、视频、配音生成与云同步尚未接入。首页《末班列车》为原创演示项目，不代表 AI 生成效果。

## 立即使用

- 仓库：<https://github.com/yanyang-commits/ai-manga-studio>（初始为私有）
- 站点：<https://mangaflow-studio.leoyang6667.chatgpt.site>（默认仅站点所有者访问；部署状态以实际发布结果为准）
- 本地启动：安装 Python 3，运行 `python3 -m http.server 3000 --directory dist`，访问 <http://localhost:3000>。
- 无 npm 安装步骤，无编译步骤，无运行时第三方依赖。不要直接双击 HTML 文件：浏览器对 ES 模块及本地存储有来源限制。

## 已实现

- 五个独立 HTML 页面：创作首页、工作台、提示词库、全流程指南、使用说明。
- 多项目创建 / 切换 / 删除；六阶段内容编辑与手动完成标记。
- 浏览器 localStorage 保存，JSON 导入、导出与跨设备迁移。
- 分镜增删、上移，记录画面、运镜、对白、时长，统计与目标时长的差值。
- 结合企划、剧本、角色、已有分镜和制作备注生成阶段提示词，可复制到外部 AI 工具。
- 六类提示词模板，可关键词搜索和按阶段筛选。
- Markdown 制作方案、适合表格软件打开的 UTF-8 BOM CSV 分镜表。
- 交付检查清单、原创示例项目、键盘可达控件、移动端断点。
- 无追踪脚本、外部字体或用户密钥输入。示例不会覆盖已有项目。

## 技术选择

| 层 | 当前选择 | 原因 / 升级路径 |
| --- | --- | --- |
| 页面 | 原生 HTML5 + CSS | 静态可托管，内容页可直接读取，无框架升级负担 |
| 交互 | 原生 ES Modules | 逻辑分模块，不依赖打包器 |
| 数据 | localStorage + JSON schema v1 | 先验证流程需求；后续可换云端 Repository |
| AI | 纯函数提示词组装 + 未启用的 HTTP Provider | UI 不绑定模型厂商；未来由服务端保管密钥 |
| 测试 | Node 内置 test + Python 链接检查 | 零测试库依赖 |
| 部署 | `dist/` 静态目录 | 可移至其他静态托管；当前使用 Sites 私有站点 |

目前没有用户账号、服务端数据库、支付、队列或模型账单。加入真实 AI 生成时再引入后端，避免初期维护成本。

## 首页信息架构

1. **核心价值与两个入口**：打开工作台 / 体验示例，立即理解产品。
2. **六阶段流程**：企划 → 剧本 → 角色 → 分镜 → 制作 → 交付，可直接进入各阶段。
3. **工作台与结构化提示词说明**：展示用户现在就能做的事。
4. **精选提示词模板**：从剧本、角色、分镜任务开始。
5. **底部创作入口与功能边界**：提醒本地保存和未接入真实模型。

## 开发与检查

使用 Node.js 20 或更新版本，Python 3：

```sh
npm run check
npm test
python3 scripts/check-links.py
npm start
```

修改 HTML/CSS/JS 后刷新浏览器即可。`dist` 是源文件，不需要重新构建。GitHub CI 执行语法、核心逻辑、链接检查；不会自动把项目公开。

## 数据与边界

- 项目存储于当前域名、当前浏览器，**没有云端备份**。更换浏览器或清除网站数据会丢失本地记录。
- 最多 30 个项目，每个项目最多 100 个镜头；JSON 导入上限 2MB。实际容量取决于浏览器；存储失败会明确提示，并保留内存数据供导出。
- 导入采用字段白名单、长度限制及数值校验；富文本不执行，用户内容通过转义渲染。
- CSV 对公式起始字符作防护；这不是多租户安全边界。
- 任何未来 API 密钥必须只放在服务端环境变量。`ai-provider.js` 未被页面引用，不会发出生成请求。
- 素材授权、平台内容政策与成片质量需要人工核查。清单只辅助工作。
- 未添加开源许可证；如需要公开复用，可由仓库所有者选定许可证。

## 推荐迭代顺序

1. **v0.1 当前**：跑通一个短片项目的手动生产流程。
2. **v0.2 文本 AI**：服务端生成剧本 / 分镜，先预览、再由用户确认写入；鉴权、限流、费用上限与错误重试同步上线。
3. **v0.3 项目云同步**：账号、项目权限、对象存储、版本记录及导入导出迁移。
4. **v0.4 图像与声音**：角色参考、静帧、TTS，异步任务队列与费用确认。
5. **v0.5 动态与交付**：视频任务、素材状态、人工挑选与剪辑包导出。
6. **v1.0 商业化**：在真实使用与成本验证后再加入额度、订单、团队协作和公开 SEO 内容。
