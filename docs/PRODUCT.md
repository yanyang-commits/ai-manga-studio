# 产品规划

## 定位

「漫序 MangaFlow」是一套面向中文独立创作者的漫剧生产工作台。首要任务是帮助用户完成第一部 60 秒小作品，降低从想法到可制作分镜之间的组织成本。初期不做模型聚合商城，也不承诺一键全自动成片。

目标用户：有故事与视觉兴趣、需要组织剧本/角色/分镜的个人创作者；其次是 2—5 人小团队。主流程允许跨阶段反复修改，不强迫顺序解锁。

## 首批页面

| 页面 | 任务 | 主要操作 | 产出 |
| --- | --- | --- | --- |
| 首页 `/index.html` | 理解价值，开始创作 | 打开工作台、载入独立示例、进入阶段 | 第一个项目 |
| 工作台 `/studio.html` | 管理一部作品的完整上下文 | 新建/切换、六阶段编辑、分镜排序、检查清单、导出 | JSON、Markdown、CSV |
| 提示词库 `/templates.html` | 找到适合当前阶段的指令 | 搜索、筛选、复制、带入工作台 | 指令文本 |
| 流程指南 `/workflow.html` | 理解每阶段输入输出 | 查看验收条件、跳转阶段 | 可执行的生产步骤 |
| 使用说明 `/guide.html` | 理解保存与能力边界 | 阅读、备份、迁移 | 避免误解与数据丢失 |

## 核心使用路径

首页 → 体验示例/创建项目 → 故事企划 → 组装提示词 → 外部 AI 生成 → 结果粘回 → 角色/分镜完善 → 外部素材制作 → 记录素材与检查 → 导出交付。

MVP 关注：用户能否在一个工作台完成企划到分镜的组织，是否复用角色设定，是否愿意保存第二个项目。首版不埋点；通过创作者访谈和自愿反馈验证，不捏造使用指标。

## 功能边界

“生成阶段提示词”是确定性文本组装。“阶段完成”是用户手动确认，不代表机器验收或完成视频制作。分镜总时长只累计用户填写值。示例中的三镜仅为片段，与 60 秒总目标的差值由 UI 显示。

## 内容与设计

中文优先。深森林绿、暖白与浅青绿色用于区分创作入口、编辑区和状态。首页原创几何场景图帮助理解漫剧制作主题；不使用虚构客户、订单或平台排名。所有编辑输入有标签、键盘焦点和本地保存状态。
