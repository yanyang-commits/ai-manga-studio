# v0.1.1 公开体验版

日期：2026-10-12。

## 发布范围

公开可访问的漫剧流程与提示词工具。游客无需注册登录；当前不提供真实模型生成、云同步、团队协作、收费或成片渲染。工作台内容仅在访客当前浏览器保存。

发布变化：游客入口与隐私说明，项目复制，全部项目 JSON 备份/导入，剪贴板降级弹窗，其他标签页修改检测，资源版本号，页面元信息、站点地图、robots、404 文档、反馈入口和完整 README。

## 部署和运维

- `dist/` 包含完整静态输出，无 npm 依赖、数据库迁移或 API 密钥。
- `npm run check`、`npm test`、`python3 scripts/check-links.py` 是发布前检查；GitHub Actions 复用。
- Sites 当前站点 ID 保持不变；公开访问通过原生 Sites 访问配置设置。
- GitHub 更新和 Sites 部署是两条独立操作，不会因为提交 GitHub 就自动更新已上线站点。
- 未来回滚：选择前一个已保存的 Sites 版本部署；保留 public 访问模式。回滚前比较 Project schema，不能自动降级或清理访客数据。
- 当前 schemaVersion 保持 1，原本地项目可以继续读取。
- 内容页的抓取许可不保证搜索引擎一定收录。
- 静态 404 页面已提供；实际未知路径状态码与映射由托管服务控制。

## 仍有边界

浏览器视觉与完整交互验收未完成：当前执行环境缺少 Sites 要求的 control-browser 能力，不能把单元测试当成浏览器验收。QA.md 保留明确的手机/桌面检查步骤。站点适合作为公开体验版继续收集反馈，不应宣传成全自动 AI 漫剧平台。
