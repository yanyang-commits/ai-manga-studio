# v0.1.1 公开体验版验证记录

验证日期：2026-10-12。

## 已通过

- 三个 JavaScript ES Modules 的 Node 语法检查。
- 10 项自动回归：项目 JSON 往返、无效格式拒绝、导入限制、六阶段提示词上下文、无效阶段回退、CSV 转义与公式防护、Markdown 完整导出、项目数据隔离、批量备份往返、批量导入原子校验。
- 六个 HTML 页面内的本地链接和静态资源存在性检查。

## 当前未完成的验证

当前 managed Sites 环境未提供 Sites 技能要求的 control-browser 能力，因此没有启动本地预览服务器，也没有完成桌面/手机浏览器视觉或交互验收。响应式断点和可访问控件已写入代码；自动单元测试不能证明完整 UI 行为。

## 浏览器手工验收清单

1. 1440px 桌面与 390px 手机宽度：首页、导航、模板卡片无横向溢出；可用 Tab 遍历。
2. 首页体验示例：新建《末班列车》，已有项目不受影响。
3. 新建项目并修改六阶段文本，刷新并切换项目，确认恢复。
4. 添加两镜、编辑镜头时长、上移、删除；累计时长实时正确。
5. 生成并复制提示词，检查项目上下文；修改项目后重新生成。
6. 导出 JSON，再导入，形成新项目且内容一致；旧项目未覆盖。
7. 打开 Markdown 与 CSV，检查中文、换行、引号与全部镜头。
8. 模板关键词搜索、阶段筛选、无结果状态、工作台跳转。
9. 存储禁用/配额失败时展示提示，并仍能导出内存项目。
10. 取消删除不改变项目；确认删除只删除当前项目。

发布是否成功以 Sites 原生部署返回值为准，GitHub 提交是否成功以 main 分支实际引用为准。没有将这些服务操作与浏览器视觉验收混为一谈。

11. 无登录状态直接打开首页和工作台；游客不应被引导至账号授权。
12. 全部备份包含所有项目，导入失败不产生部分记录；容量超限有提示。
13. 两个标签页同时打开项目，任一更新后另一页提示先备份再刷新。
14. 禁止剪贴板权限后点击复制，弹窗完整展示原文并可手动复制。
15. 原站点游客数据应在同源升级后继续存在。
